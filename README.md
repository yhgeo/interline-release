# 行间 · Interline · 分发仓

本仓只放**安装包、更新清单、服务地址**，不放源码、不放密钥、不放内容包。

## 下载

- iOS：`releases/ios/Interline-<version>.ipa`
- Android：`releases/android/Interline-<version>.apk`

## 文件

| 文件 | 用途 |
|---|---|
| `latest.json` | App 检查更新 |
| `license.json` | 授权服务地址与备用地址 |
| `releases/` | IPA / APK |
| `notes/` | 版本说明 |

## 内容包

评论包体积大，按卷加密后走网盘；链接写在服务端 manifest 里，不在本仓。
