# 行间 · Interline

把网文的**段落评论**嵌进正文里读的阅读器。点一段文字就能看到这一段下面的段评和楼中楼，正文与评论分层，互不遮挡。

一个 App，多本书共存。正文、评论、时间线都由服务端按书下发；换书不串进度、不串授权。

本仓只放**安装包和版本清单**，不放源码、密钥、内容包。

## 安装

- **iOS**：下载 IPA，用 AltStore / TrollStore / 自签工具安装到手机。
- **Android**：下载 APK，允许「安装未知来源」后安装。安装包用行间发布密钥签名，可直接覆盖旧版升级。

## 第一次使用

### 1. 找到设备码

打开 App，首页（书架）底部有「设备码」一行，是一串 32 位十六进制字符。

把这串设备码发给管理员，请管理员在管理面板批准这台设备和要读的书。

### 2. 刷新授权

进入某本书的**书详情页**，顶部「授权」卡片显示当前状态：

```text
本设备已获授权       → 可以下载、可以读
等待管理员批准       → 等管理员批准后回来点刷新
授权已吊销           → 这本书不能读了
尚未连接服务器       → 检查网络后再刷新
```

状态不是「已获授权」时，点卡片里的「刷新授权」。批准后状态变为「本设备已获授权」，App 会自动取这本书的离线密钥。

每本书单独授权：A 书授权不影响 B 书，吊销只停当前书。

### 3. 选书、下载正文

书库从服务端自动拉取书目，当前有《诡秘之主》《玄鉴仙族》两本。点书进入详情页：

- 「正文」卡片 → 点「下载」。下载完校验 sha256，通过后就能读。
- 底部「开始阅读」按钮在这期间显示下载进度；网络或授权有问题时，按钮上会直接显示原因（离线、未授权、服务器关闭下载等），点一下收起提示。

### 4. 下载评论包

书详情页「评论」卡片列出各卷。每卷单独下载、单独显示状态：

- 点对应卷的「下载」，从服务器拉取并校验。
- 卷太多时只下载当前在读的卷即可，其他卷不影响正文阅读。

如果服务器暂时关闭了某类包下载，按钮上会提示「服务器已关闭评论下载，请从网盘或本地导入」。

### 5. 下载时间线（可选）

书详情页「时间线 / 模块」卡片里有「时间线」包。下载后：

- 章节标题下显示本章年份与出场人物。
- 顶栏显示当前章年份。
- 目录里也能查整条时间线。

时间线是可选项，不下载不影响正文和段评。

### 6. 阅读

- 目录选章，正文按段落排；横向翻页或上下滚动都支持。
- 段尾显示段评数，点开看根评论和楼中楼。
- 章标题本身也有评论入口（标题右侧数字）。
- 阅读进度自动保存，退出重进回到原处。
- 段评防剧透：按时间线判断「这个人还没出场」「后面才会死」等，默认开启，可在设置里调。

## 设置

设置分四档：

| 档 | 内容 |
|---|---|
| 阅读 | 字号、行距、主题、页边距、翻页方式、顶栏 |
| 防护 | 段评防剧透、关键词分组、智能识别 |
| 数据 | 正文/评论占用、导入数据包、时间线/属性标签开关 |
| 关于 | 检查更新、意见反馈、联系方式 |

**时间线 / 属性标签**（设置 → 数据）：

- 显示时间线：总开关。
- 章标题下显示年份与人物 / 悬浮顶栏显示年份：分别控制两处。
- 世次显示：仅当前书带世次数据时出现，可切「第N代 / 第N世」。
- 属性标签：默认隐藏标签名前缀（序列 / 途径 / 修为…）；按当前书的属性种类生成「隐藏整类」开关，切书时自动换成那本书的种类。

**数据占用**只显示所有书正文 / 评论的总大小，不显示包版本（各书数据包版本本来就不同）。

## 导入本地数据包

App 支持从系统文件选择器导入 JDK4 加密数据包（正文 / 评论 / 时间线自动识别）。导入走本地，不依赖服务器下载开关，离线也能用。

- 只接受 JDK4 加密包；旧格式与口令包不支持。
- 导入时按包内记录的书籍标识自动归位，别的书的包也能直接导进来。
- 导入后到对应书详情页查看状态。

需要数据包时优先走 App 内服务器下载。

## 更新

1. 打开 App，到设置 → 关于 → 检查更新；或书详情页刷新。
2. App 读 `latest.json`，有新版本会提示。
3. 正文 / 评论更新用 sha256 判断：服务端换了包只提示「更新」，不后台自动替换已装的包。点「更新」才下载新包。

## 常见问题

| 现象 | 处理 |
|---|---|
| 一直「等待管理员批准」 | 把首页底部的设备码发给管理员，批准后点书详情的「刷新授权」 |
| 按钮上显示「无法连接服务器」 | 检查网络；已下载正文的书仍可离线阅读 |
| 按钮上显示「服务器已关闭…下载」 | 该类包暂时不开放服务器下发，等管理员恢复或用本地导入 |
| 设备码在哪 | 首页（书架）最底部 |
| 服务端加了新书但书架没显示 | 点首页标题栏的刷新按钮（iOS 下拉刷新）；书详情页的「刷新授权」不刷书目 |
| 导入包后没段评 | 确认导入的是 JDK4 包；到对应书详情页确认状态 |
| 第一章段评没出来 | 刷新正文或重进章节（评论包挂载后会自动刷新） |
| sha256 不匹配 | 删除该包重新下载，不要手动改包 |
| Android 报 Cleartext HTTP not permitted | 确认装的是 0.2.x 之后的 APK |
| 存储不够 | 只下载当前在读的卷；评论包按卷几十 MB 不等 |
