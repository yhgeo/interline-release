# 0.2.73

## 下载

- 中文包文件名 URL 编码修复；iOS 增加非 ASCII 兜底编码，正文/评论下载不再报「网络不可用」。
- 服务端 manifest 的 `packages.text.url`、`reviews[].url`、`modules[].url` 统一 percent-encoding。

## 授权

- 管理页授权只保留「授权天数」，去掉授权开始/到期输入。
- 设备行授权记录只显示书名 + 授权时间。
- 单书吊销后客户端立即置为吊销、清本地 CEK，不能继续看书。
- 每本书换章次数单独记录；使用记录卡片不再放吊销按钮，单书吊销只在授权区块。

## 数据

- 玄鉴正文/评论继续使用原项目 `output/pkg/text.jdpk` / `reviews.jdpk` 最新明文包。
