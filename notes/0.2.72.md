# 0.2.72

## 客户端

- 正文/评论不再后台自动换新；详情页显示「更新」，由用户手动点。
- 详情页显示 manifest 里的数据包标签：`书名-正文`、`书名-评论-第N卷…`。
- keyfile notAfter 独立为 CEK 离线有效期；临近过期联网换 keyfile，过期后必须联网。
- 上报 `bookId` / 章节标题，管理端按书显示使用记录。

## 数据

- 玄鉴正文改用原项目 `output/pkg/text.jdpk` 明文包重新加工，目录保留卷/段数/评论数。
- 服务端包命名：`玄鉴仙族-正文.jdpk`、`玄鉴仙族-评论-第一卷溪里青玄.jdpk`、`诡秘之主-正文.jdpk` 等。
- manifest 增加 `bookTitle`、`label`、`volumeIndex`、`kind`。

## 管理端

- 设备详情按书显示使用记录：当前章/标题、换章次数、首次/最近、数据包版本。
- 授权可设开始时间、到期时间、CEK 离线有效期；支持按书吊销。
- 详情块保留「授权」，删除设备行快捷授权；刷新自动加载。
