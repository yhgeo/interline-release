# iOS 0.3.3

Android 保持 0.3.0 冻结；仅在用户明确下达同步要求后才更新。

## iOS

- 恢复书籍详情页评论卷的本地持久化；快照按 `bookId` 校验，切书不会串。
- 设备码从书详情「授权」卡片移到首页标题下方，长按复制。
- status 协议解析服务端 `message`，并回传 `msgAck`，服务端消息现在能收到且不会重复弹。

## 服务端

- 新增设备时间线日志：注册 / 消息 / 授权 / 下载 / 反馈 / 管理操作；面板设备行「日志」可查看。
- `/v1/device/status` 返回未读消息；`msgAck` 会确认消息。
- overview 增加 `activeFormal` / `activeTrial` 计数，面板显示在「已授权」旁边。
- 面板新增「删除已隐藏」，批量删除隐藏/归档设备及其授权、下载记录。

## 验证

- 消息端到端：注册 → 定向发送 → status 收到 → ack → status 不再收到 → 设备时间线可见。
- 项目审计、文档 lint 通过。
