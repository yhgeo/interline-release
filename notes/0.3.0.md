# 0.3.0

统一稳定版，iOS 与 Android 版本号对齐。

## 客户端

- 多书状态按 `bookId` 隔离：进度、CEK、授权、包文件、使用记录、换章次数。
- 单书吊销只影响当前书；客户端按书清 CEK。
- 每本书基础信息本地缓存，先显示缓存，网络回来覆盖。
- 正文/评论 sha 变化只提示更新，由用户手动下载。
- 首页按书显示授权状态，不再复用单本全局状态。
- 上报每本书已下载文件；吊销后服务端保留记录。

## 服务端

- 书籍目录自动发现；新书部署不需要改代码。
- 每本书独立 CEK；重复 CEK 拒绝注册/部署。
- 管理面板按书显示使用记录与已下载文件。
- 授权输入收敛为授权天数与 CEK 离线有效期。

## 数据与包

- 正文：`<书名>-正文.jdpk`。
- 评论：`第N卷<卷名>.jdpk`，不带书名前缀。
- 包 URL 强制 percent-encoding；下载签名使用 manifest 原始 `file`。

## 工程治理

- 新增 `PRODUCT / ROADMAP / ARCHITECTURE / TEST-MATRIX / VERSION-POLICY / AUDIT` 文档。
- 新增 `tools/project-audit.js`，固化版本、文档、协议、包命名与 CEK 唯一性检查。
- 停止逐 bug 发版；后续按测试矩阵一次性发布。
