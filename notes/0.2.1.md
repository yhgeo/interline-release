# 0.2.1

## 界面
- 书库改成通用书架：封面、书名、作者、授权/正文/评论状态、阅读进度
- 入口固定为 书库 → 书详情 → 阅读器；阅读器顶栏可返回书架
- 全站改水墨配色（纸底、墨字、赭石强调），去掉 Material 默认蓝
- 设置页滑杆/开关/分段跟随水墨主题
- 阅读页错误态带「重试」，章节读取失败会自动重下一次正文

## 数据
- 评论包按卷下载：`reviews-<卷>.jdpk`，卷列表来自 manifest
- 书详情显示正文版本/大小、每卷评论大小与下载状态
- 正文下载失败、包损坏时保留网盘备用入口

## 服务端
- 管理面板重做：统计、状态筛选、搜索、设备表、设备抽屉
- 新增消息发送（全部/单设备）、反馈列表、自动批准开关
- 口令存 localStorage，刷新不丢
