# iOS 0.4.8

Android 保持 0.3.0 冻结；仅在用户明确下达同步要求后才更新。

## 时间线 v2

双书时间线包升级到通用 v2：

- 诡秘之主：1403 章 / 843 人物实例 / 4 类 trait（rank/path/identity/org）
- 玄鉴仙族：1641 章 / 5771 人物实例 / 3 类 trait（realm/generation/faction）

包内结构：

```json
{ "timeline": { "meta": { "schema": 2, "traitKinds": [...] }, "chapters": [...] } }
```

人物属性统一为：

```json
{ "kind": "rank", "value": "...", "label": "序列", "confidence": 0.85 }
```

旧字段 `realm/gen/shi` 原样保留作投影，旧逻辑不丢。

## iOS

- `TimelineTrait` 解码与渲染。
- 有 traits 时按 `label value` 显示。
- `generation` 仍服从「世次显示」开关。
- 无 traits 的包继续走旧投影字段。
- 目录页仍只读 `timelineIndex`，不解包。

## 通用扩展

新书只需：

```text
pipeline/profiles/<bookId>/timeline-profile.json
books/<bookId>/build/enrich/timeline.json
```

不改生成器、不改客户端。
