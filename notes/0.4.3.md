# iOS 0.4.3

Android 保持 0.3.0 冻结；仅在用户明确下达同步要求后才更新。

## iOS

- 时间线只支持新版 `chapter` 字段，移除旧 `no` 兼容。
- 章节标题下只显示：
  - 年份 / 纪年
  - 本章人物（年龄 / 境界 / 世代 / 亡）
- 通用模块卡片框架保留但当前版本关闭；设置里不再显示「章标题下显示模块卡片」开关。
- 顶栏时间线年份继续保留。
