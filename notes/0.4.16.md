# 行间 Android 0.4.16

## 安全修复

修复「书未授权也能下载数据包」：

- 服务端 `/v1/books/:id/package/:file` 此前只校验设备级 active，没有校验该书授权。
  现补上与 `/key` 端点相同的每书授权规则：`licenseState(licenses[deviceKeyId:bookId])`
  不是 active 就返回 403 `DOWNLOAD_LICENSE`。
- 客户端正文 / 评论 / 模块三个下载入口补前置授权门禁：未授权 / 等待批准 / 已吊销
  分别给明确提示，不发下载请求。

服务端已部署并重启。未授权的书现在下不到包，已授权的书不受影响。
