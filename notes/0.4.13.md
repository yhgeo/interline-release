# 行间 Android 0.4.13

本轮按反馈调整状态显示与授权区布局，并彻底移除旧版兼容。

## 状态显示

- 书页底部按钮区按来源显示状态，不再一律当成服务器限制：
  - 下载进度
  - 服务器关闭该类下载
  - 离线 / 无法连接服务器
  - 未授权 / 授权失效 / 等待批准
- 下载错误文案细分：429 次数用尽、401/403 无权限、503 忙、网络不可达、sha 校验失败。

## 布局调整

- 设备码移到首页（书架）底部，去掉「复制设备码」。
- 授权状态与「刷新授权」保留在每本书的书籍详情页。
- 设置 → 数据只显示所有书的正文 / 评论总占用，不显示版本（各书包版本不同）。

## 旧版兼容清理

- 包格式只剩 JDK4（zlib + AES-GCM），移除 JDK3 / JDK2 / JDPK 读取与口令派生。
- 本地导入按 JDK4 包头 `bookId` 取对应书 CEK，可跨书导入。
- 移除旧单书 bookId 迁移、旧单卷 `reviews.jdpk`、旧命名评论包、`reviews-*` 挂载。
- 移除防剧透规则的历次迁移逻辑与旧规则常量。
- 移除旧口令包 mismatch 上报字段。
