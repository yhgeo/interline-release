# iOS 0.3.5

Android 保持 0.3.0 冻结；仅在用户明确下达同步要求后才更新。

## iOS

- 未授权时点正文下载：直接拦截，不拉 manifest，不显示评论卷列表，提示「当前书未获得授权，请先同步授权」。
- 403 下载错误文案改为可读提示，不再只显示 HTTP 403。
- 本地导入前先强制同步授权，服务端刚批准也能继续导入。
- 未授权导入提示改为「未获得授权」，不再误报「不是有效的数据包」。
- 本地导入支持 JDK4 加密包（`诡秘之主-正文.jdpk` 这类服务端包），用当前书 CEK 识别正文/评论/时间线。
- 正文下载恢复进度条与百分比。

## 管理面板

- 展开的设备详情行改用 `var(--bg2)` 背景 + 左侧强调色边线，与折叠行区分。

## Android

- 冻结在 0.3.0；同步门槛为用户明确下达命令。
