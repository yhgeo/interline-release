# iOS 0.4.0

Android 保持 0.3.0 冻结；仅在用户明确下达同步要求后才更新。

## 语义修正

服务端设置的正确含义：

- 选中＝该类数据包不从服务器提供。
- 用户需要自行从网盘 / 本地导入。
- App 内文件导入不受任何限制。
- 服务器下发始终可用，除非管理员在设置里关闭对应类型。

## 服务端

- 字段改为 `serverBlockedKinds`。
- 旧 `serverOnlyKinds` 作为兼容字段会自动迁移。
- 下载路由按文件名判断包类型：
  - `text` / `reviews` / `modules`
- 命中关闭类型时返回 `451 SERVER_DOWNLOAD_DISABLED`。
- 面板文案改为「限制服务器下发（全局默认）」。
- 取消勾选后由「保存」按钮统一提交。

## iOS

- 移除本地导入限制逻辑。
- 设置页提示改为「服务器已关闭下载：…（可从网盘或本地导入）」。
- 451 错误提示：
  ```text
  服务器已关闭该类型下载，请从网盘或本地导入
  ```
- 书详情保留模块 / 时间线卡片，可直接下载、更新、阅读。

## Android

- 冻结在 0.3.0；同步门槛为用户明确下达命令。
