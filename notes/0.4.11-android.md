# 行间 Android 0.4.11（与 iOS 功能对齐）

本轮把 iOS 现行实现同步到 Android。时间线 v2、通用世代基准、属性标签隐藏、模块列表持久化全部对齐；新增书无需改客户端。

## 时间线 v2 通用格式

- 章节号只认新版 `chapter` 字段，不兼容旧 `no`。
- 人物属性统一读 `traits[]`（`kind / value / label / confidence`），数字 value 自动归一成字符串。
- 无 traits 时退回旧投影字段 `realm / gen / shi`。
- `meta.traitKinds` 驱动设置页，题材差异不再写死进代码。

## 属性标签显示

- 设置 → 数据 → 属性标签：默认隐藏标签名前缀（序列 / 途径 / 修为…）。
- 按 `meta.traitKinds` 生成「隐藏整类标签」开关，按 kind 保存，切书自动切换。
- 章节标题下、顶栏、时间线详情页使用同一套隐藏规则。

## 世次显示通用化

- 「世次显示」只在当前书人物带 `shi` 字段时出现，其他书自动隐藏。
- 第 N 代 = `shi − 全书最小 shi + 1`，不再写死减 8。
- 可切换「第N代 / 第N世」。

## 模块 / 时间线列表

- 时间线是 manifest `packages.timeline` 一等包，合入模块列表统一下载 / 更新。
- 模块列表与正文、评论卷一样进 manifest 快照，离线打开书详情仍显示已安装 / 待更新状态。
- 下载走统一签名与 sha256 校验；`serverBlockedKinds` 在下载前本地预检。

## 新增书

- 服务端部署 `manifest.json` + `cek.hex` + `packages/*.jdpk`，客户端自动发现。
- iOS / Android 双端功能与 UI 观感一致，均以 `docs/40-clients/ios-implementation-guide.md` 为准。
