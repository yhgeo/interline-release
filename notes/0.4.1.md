# iOS 0.4.1

Android 保持 0.3.0 冻结；仅在用户明确下达同步要求后才更新。

## 修复

- 服务器关闭正文下载后，点击「下载」立即报错，不再出现一闪而过的加载进度条。
- 评论、模块下载同样先做本地预检。
- 模块 / 时间线改为和原项目一致的内嵌展示：
  - 内容嵌入正文页章标题下方。
  - 时间线显示年份和本章人物年龄 / 境界 / 世代。
  - 其他模块按本章相关条目生成紧凑卡片。
  - 书详情和目录里的模块页只负责下载 / 更新，不再直接阅读文件。
- 新增设置开关「章标题下显示模块卡片」。
- module-timeline 包可作为时间线数据源，不再要求传统 `timeline.jdpk`。
