# iOS 0.3.2

Android 保持 0.3.0 冻结，仅在用户明确下达同步要求后才更新。

## 修复

- 进入书籍详情页不再自动下载正文；正文下载/更新只由详情页按钮触发。
- 评论卷列表按当前 bookId 隔离，本地快照只在文件确实属于当前书时保留。
- 顶栏章节标题通过轻量 ticker 即时更新，滚动跨章不再等存储提交。
- 评论包挂载变化后清空章节缓存，修复「下载第一卷后第一章评论消失、后面正常」。
- 移除客户端 files 上报、服务端 files 存储和管理面板「已下载文件」展示；下载记录以 downloads.json 为准。

## 服务端

- `/v1/books` 继续返回 `textSize/reviewsSize`。
- 服务端不再保存 `bookUsage[bookId].files`。

## Android

- 冻结在 0.3.0；同步门槛改为用户明确下达命令。
