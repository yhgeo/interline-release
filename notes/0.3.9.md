# iOS 0.3.9

Android 保持 0.3.0 冻结；仅在用户明确下达同步要求后才更新。

## 服务端

- 设置文案修正：
  - 标题：`限制 App 内导入（全局默认）`
  - 说明：`选中＝该类包不能从文件导入，只能走服务器下发；网盘下载不受影响。点「保存」后生效。`
- 取消勾选不再即时保存，统一由「保存」按钮提交。
- 逻辑说明：
  - 选中 = 该类包禁止 App 内文件导入，只能由服务器下发。
  - 不选中 = 允许 App 内文件导入。
  - 服务端下发始终可用，不受该设置影响。
  - 网盘下载始终不受影响。

## iOS

- 书详情页新增「模块 / 时间线」卡片。
- 直接显示已部署模块：下载 / 更新 / 阅读。
- 点击「阅读」进入通用模块详情页。
- 目录页原「模块」入口保留。

- 冻结在 0.3.0；同步门槛为用户明确下达命令。
