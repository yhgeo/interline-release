# 行间 Android 0.4.12

本轮修复 5 个问题，功能与 iOS 保持一致。

## 修复

1. **章节跳转不再跳到前面几章**
   - 根因：换包 / 外部跳章时用 `sections.indexOf(no)`（窗口内章序号）当 `LazyColumn` 行下标定位，实际行里有章 Header + 每个段落，下标完全不同，滚到了前面几章。
   - 改为用 `headerState[章号]` 定位到该章 Header，与目录 / 搜索跳转一致。

2. **书页按钮区显示报错与状态**
   - 下载类型限制（正文 / 评论 / 模块）等报错信息临时覆盖显示在书页底部「开始阅读」按钮上，点一下收起。
   - 下载进度仍在该按钮显示。

3. **授权码移到首页底部**
   - 设备码、授权状态、刷新授权 / 复制设备码从书详情页移到首页（书架）底部。

4. **设置 → 数据精简**
   - 只显示正文 / 评论的占用大小，去掉时间线分项。

5. **导入本地数据包失败**
   - 根因：安卓用当前书密钥解所有导入包，且 JDK4 头 flags 读取位置错误。
   - 改为读取 JDK4 包头的 `bookId`，按包归属取对应书的 CEK，支持跨书导入。
   - 修正 JDK4 flags 读取（u16@6）。
   - 移除 JDK3 / 口令导入流程，只接受 JDK4 加密包，与 iOS 一致。
